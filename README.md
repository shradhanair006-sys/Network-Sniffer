# Network Sniffer

## Project Description 
A python-based Network Sniffer that captures and monitors network [ackets using the scapy library .

##Objectives
- Capture network packets.
- Display source and destination IP addresses.
- Identify TCP,UDP,and ICMP protocols.
- Display packet details.

## Technologies Used
- Python 3
- Scapy
- Ubuntu Linux

# Installation
Install Scapy using:
pip install scapy 

## How to run
Run the following command
sudo python3 sniffer.py

# Output
The program displays captured packet information,including IP addresses,protocols and packet details.
